# Auth Addon (dev)

The development build of the [Auth Addon](../armhub_auth/DOCS.md), tracking `main`. Use the normal add-on unless you're testing something unreleased.

Only run one of the two add-ons at a time, and point the integration at this one with the add-on URL `http://60356650-armhubmeter-dev:8099`. This add-on keeps its own data, so it logs in afresh and needs its own email code setup.

A dev build has no version number, so Home Assistant won't offer updates. Rebuild or reinstall it to pick up the latest image.
